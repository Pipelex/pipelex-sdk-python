# pipelex-sdk — moved

This repository is archived. `pipelex-sdk`, the Python client for the Pipelex hosted API, now lives in the `python/` directory of [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/python), beside its TypeScript twin, the starters and the method-app templates.

The package keeps its name and is published to PyPI from there. The last version released from this repository was 0.16.0, and every later version comes from `Pipelex/pipelex-sdk`.

- **PyPI:** [`pipelex-sdk`](https://pypi.org/project/pipelex-sdk/), import package `pipelex_sdk`
- **Source:** [`python/` in Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/python)
- **Issues and pull requests:** [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/issues)
